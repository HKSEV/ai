# MySQL 검증 기록

검증일: 2026-11-10 (한국 시간)

## 검증 환경

- MySQL Community Server **8.4.7**를 별도로 구동하고 실제 MySQL 연결로 검증했다.
- 검증용 `nowon_resume_qa` 데이터베이스와 가상 음식점·메뉴·회원 정보를 사용했다.
- 애플리케이션의 SQLAlchemy 모델로 테이블 12개를 생성했다.
- FastAPI `TestClient`로 실제 라우터·인증 의존성·서비스·MySQL 저장 계층을 호출했다.
- 카카오 계정 확인과 Gemini의 구조화 응답은 모의 응답으로 대체했다. 실제 외부 계정 로그인 및 실제 Gemini 호출 성공을 의미하지 않는다.

## MySQL 통합 검증

총 **36개 확인 항목 통과**. 다음 흐름을 포함한다.

동일한 시나리오는 `backend/scripts/verify_mysql.py`로 다시 실행할 수 있다. MySQL에 `_test`로 끝나는 전용 데이터베이스를 미리 만들고, 해당 DB의 테이블 초기화를 명시적으로 허용해야 한다.

```bash
cd backend
TEST_DATABASE_URL='mysql+pymysql://사용자:비밀번호@127.0.0.1:3306/nowon_food_test?charset=utf8mb4' \
  uv run python scripts/verify_mysql.py --reset
```

이 명령은 지정한 테스트 DB의 애플리케이션 테이블을 초기화한다. 운영 DB 이름은 받지 않는다.

| 범위 | 확인한 결과 |
| --- | --- |
| DB 초기화 | MySQL에서 애플리케이션 테이블 12개 생성 |
| 외부 설정 누락 | 카카오 키가 없을 때 로그인 성공으로 처리하지 않고 503 반환 |
| OAuth와 가입 | 상태값 교환 후 서버 세션 발급, 서로 다른 두 회원 분리 |
| 재로그인 | 동일 카카오 식별값으로 재로그인했을 때 변경한 닉네임 유지 |
| 프로필 | 선호 음식·가격대 저장, 별도 SQL 세션에서 선호 음식 재조회 |
| 닉네임 | 다른 회원의 닉네임과 중복되면 409 반환 |
| 주소 | 저장 후 재조회, 다른 회원에게 목록 비공개, 수정 요청 차단 |
| 사진·영수증 | 이미지 저장, 영수증의 다른 사용자 조회 차단, 게시글 사진은 커뮤니티에서 조회 |
| 방문 기록 | 직접 입력한 방문만 저장, 영수증 첨부 후에도 `not_verified` 유지 |
| 리뷰 | DB 저장·유형별 목록·상세·본인 수정·삭제, 타인 수정·삭제 차단 |
| 추천 | 저장 음식점 조회 → 모의 Gemini 조건·순위 → 근거가 있는 카드 구성 |
| 메뉴 계산 | 9,000원 1인 메뉴 2개의 예상 총액 18,000원, 1인당 9,000원 계산 |
| 미확인 정보 | 영업 정보는 `확인 필요`, 대기·재방문율 등 미연동 수치는 `null` 유지 |
| 후속 대화 | 동일 대화에서 조건 변경과 메시지 4개 저장, 검색 기록 2개 저장 |
| 개인정보 | 다른 회원의 대화 조회 차단, 외부 Origin의 변경 요청 차단 |
| 기록 분리 | 추천 요청 후 방문 기록 수가 늘어나지 않음 |
| 삭제 | 대화 삭제 시 메시지·검색 기록 연쇄 삭제, 리뷰 삭제 시 연결 사진 정리 |
| 로그아웃 | 서버 세션 제거 후 인증 조회에서 401 반환 |

## 정보 정확성 회귀 검증

`backend/tests/test_restaurant_facts.py`의 4개 테스트 통과.

1. 해당 요일의 영업시간이 없으면 `확인 필요`를 반환한다.
2. 명시된 요일 휴무는 `휴무일`로 안내한다.
3. 자정을 넘는 영업시간은 다음 날에도 정확하게 계산한다.
4. `노원역` 검색 결과의 주소에 역명이 없어도 공급자가 반환한 지역 검색 결과를 유지한다.

```bash
cd backend
uv run python -m unittest discover -s tests -p 'test_restaurant_facts.py' -v
```

## 실제 외부 서비스 검증에 필요한 설정

카카오 앱의 REST API 키와 Redirect URI, Gemini API 키와 사용 가능한 모델 ID를 설정한 후 실제 브라우저에서 로그인·추천을 확인해야 한다. 외부 장소 데이터 저장은 사용 권한이 확인된 경우에만 관련 설정을 활성화한다. 영업·대기·결제 통계·외부 리뷰·영수증 검증 제공처의 계약과 실제 데이터는 이번 검증에 포함하지 않았다.
