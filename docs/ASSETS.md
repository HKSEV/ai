# 소개 화면 배경

- 파일: `next-frontend/public/images/nowon-alley.webp` (1536×1024, 321,464바이트).
- 새로 생성한 일러스트를 웹 전송용 WebP로 인코딩했습니다. 식당의 초록 차양·나무 문, 아이보리 벽, 테라코타 화분과 한식 식탁을 따뜻한 구아슈 질감으로 표현했습니다.
- 실제 특정 음식점을 설명하는 사진이 아닌 소개 화면용 그림입니다. 제목·버튼·안내 문구는 이미지에 포함하지 않고 실제 웹 컴포넌트로 구현했습니다.
- PC에서는 오른쪽 골목과 식당을, 모바일에서는 식당 입구와 식탁을 중심으로 CSS 배경 위치와 그라디언트를 조절했습니다.
